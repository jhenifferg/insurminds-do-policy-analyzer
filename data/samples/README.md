# Apólices fictícias para demonstração

Os dois PDFs desta pasta foram criados exclusivamente para testar o InsurMinds. Seguradoras, empresas, números, limites, franquias, prémios, datas e cláusulas são inventados. Os documentos não têm validade jurídica nem representam produtos reais.

- `Apolice_DO_Ficticia_A.pdf`: LMG de R$ 5.000.000,00 e franquia de R$ 50.000,00.
- `Apolice_DO_Ficticia_B.pdf`: LMG de R$ 10.000.000,00 e franquia de R$ 100.000,00.

Para testar o fluxo atual, carregue os dois PDFs na aplicação. A extração envia o texto à API OpenAI, portanto use-os apenas com uma chave configurada e após confirmar a autorização no app.
